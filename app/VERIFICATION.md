# 初版验证记录

2026-09-07，本机开发环境。

- 页面 `http://127.0.0.1:3000/` 返回 HTTP 200，浏览器实际显示 3D 方块房间和本地像素字体。
- `npm run typecheck`、`npm test`（4 项）、`npm run build` 均通过。
- 自动化移动测试覆盖大步长防穿透、房间边界、沿障碍移动、全部交互点之间的寻路以及距离限制。
- 在浏览器点击物品标签，角色实际走近物品；用 E 打开笔记本和电脑，再用 Esc 返回房间。
- 笔记保存至 localStorage，重新打开可读回；保留了现有笔记。可选 WebMCP 保存工具验证了成功返回、可见保存状态以及无效输入拒绝。
- 浏览器内 PowerShell 实际执行命令并返回 `HOME_BROWSER_OK` 和 `CTRL_C_OK`；修复默认历史目录访问错误后，打开终端显示干净的 `PS D:\myweb>` 提示符。
- 后端独立验证了真实 PTY 输出与 `Get-Location` 的 `D:\myweb` 路径；外国 Origin 和错误令牌均返回 403；关闭验证连接后活跃会话数归零。
- 落地灯能在「午后时光」和「夜色正好」之间切换。
- 检查默认预览、390×844 和 1280×800 布局；验证结束后恢复默认窗口尺寸。
- 修复了 ResizeObserver 循环报错与终端吞掉 Esc 的问题。

这是一份本地运行的初版，不包含公网部署、多人联机、建造系统或跨设备同步。Windows node-pty 关闭会话时偶尔输出内部 AttachConsole 诊断，但验证中服务持续运行，会话计数正常清理。自动化覆盖核心碰撞规则，未逐一手动遍历房间内所有坐标。
